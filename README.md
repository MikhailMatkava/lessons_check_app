# Приложение для контроля занятий

Мобильное веб-приложение для учета частных занятий.

## Возможности

- интерактивный календарь занятий;
- ученик, дата, время и стоимость каждого занятия;
- статусы «оплачено» и «не оплачено»;
- подсчет оплаченного дохода за месяц;
- подсчет текущей задолженности;
- добавление, редактирование и удаление занятий;
- сохранение данных в браузере устройства.

## Запуск

Откройте `index.html` в браузере. Дополнительная установка не требуется.

Исходная версия не содержит личных данных или истории занятий. Ученики и тарифы добавляются непосредственно в приложении.

Рабочая версия: https://uroki-mikhail.royalpenny2.chatgpt.site
